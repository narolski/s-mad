# E07: shortcut controls (resolution matching and nuisance correlations)

Terms: EER = equal error rate (lower is better, about 50% is chance). E7 = control where genuine photos are shrunk to the morphs' scale.

- **Question.** Do networks separate morphs from genuine photos by source resolution or file size instead of by morphing traces?
- **What was done.** Registered 27 Oct, run 28 Oct 2026. Scored 63 networks, including MADMamba-T, on native pools and on resolution-matched pools; correlated genuine-photo scores with native width and file size (limit: absolute Spearman rho 0.2).
- **Result.** MADMamba-T trained on data arm D1: 10.53% EER on native pools (SD 1.34, n 3) against 32.63% (SD 0.22) when resolution-matched. Plain Mamba: 34.17% against 34.37%. MADMamba-T rho(genuine score, native width) -0.40. 58 of 63 networks exceeded the 0.2 limit for width, height or file size (49 on the pooled value); only the three MADMamba-T at 256 px and one ResNet-50 and one Inception-v3 stayed inside.
- **Verdict.** The correlation hypothesis was falsified (the networks do use these properties). The resolution-match was adopted for every later number ("every number in E01-E11 is the matched one").
- **Caveats.** The first test of this idea, from the earliest wave; `CONCLUSIONS.md` lists it among "earlier numbers were flawed". It carries no claim about published detectors; later audits (A32 onward) address those.
- **Sources.** `mambamorph-code/experiments/E07_shortcut_controls/README.md` and `meta.json` (headline and hypotheses); raw table `raw/e07_scores_summary.csv` cited there; `experiments/CONCLUSIONS.md`, line "Our earlier numbers were flawed".
