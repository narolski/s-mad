## 2. Findings, most severe first

**O1 (major; I would treat it as a blocker for the oracle's meaning). The median shift measures how different the two layers look, not how far apart they sit.**
- `cv2.phaseCorrelate` on two unrelated 24 px windows returns a peak at an essentially random position within ±12 px. That gives a median magnitude of about 7 to 8 px.
- Two different people's skin and shading are mostly unrelated. Two sessions of one person are correlated and give shifts near 0 to 1 px.
- So the AUC will come out high, and "≥ 0.60 within W" will pass, whatever the real misregistration is. Smooth cheek windows inside the 12 px-eroded hull add to this.
- The peak response is printed (`me1_measure.py:78`) but nothing uses it.
- **Fix (text and code):**
  - "Null response r* = 95th percentile of the responses of phaseCorrelate(H_w window, H_w window 48 px lower, both in the eroded hull), computed per host. Statistic = median shift over windows with response > r* (at least 10 windows, otherwise not finite), together with the fraction of windows above r*. The ungated median is printed only."
  - Return `median(sh[rs > rnull])` and `(rs > rnull).mean()` from `phase_shift`.

**O2 (major). There is no check that the estimator recovers a known displacement.**
- Add a positive calibration: phase shift between R2w4 and R2w. Both carry H's texture and differ only in geometry.
- Rule: "Spearman ρ between this median shift and the mean landmark distance |mean(H,B) − mean(H,S)| inside the hull ≥ 0.5; otherwise the oracle is 'invalid (estimator)' and the result is inconclusive."

**O3 (major). The binding gain over [log E, log W] is well defined but cannot tell displacement from dissimilarity, and it sits near the ceiling.**
- The A2 review found the base at 0.888 (FRGC 0.921).
- A pure dissimilarity statistic can easily add +0.03.
- **Fix:** base = [log E, log W, median response]. Print the gain over [log E, log W] as well.
- Also use the same fold seed for the point estimate and the bootstrap. The gain uses 20261191 (`me1_read.py:213`); the bootstrap falls back to `cf_scores`'s default 20261181 (`:241`).

**O4 (major). The binding within-stratum reads pool the two databases, and there is no coverage floor.**
- The A2 review (F1) showed that pooled strata pair FRGC two-person rows with colorFERET same-person rows.
- `strat_auc` takes quantiles over both databases pooled (`bd1_read.py:43`). Within-W coverage was 0.60 in TB1.
- **Fix:** "Binding within-W, within-E and within-D reads use quintiles computed inside each database, combined with weights n_pos × n_neg. A binding read with coverage < 0.50 gives 'inconclusive (coverage)'." Add a component-bootstrap interval for the within-W AUC.

**S1 (major). The echo statistic is mostly a sharpness measure, not an echo.**
- `echo()` takes the maximum of the raw normalised autocorrelation over the lag set (`me1_measure.py:66-67`). For any smooth texture, autocorrelation falls as the lag grows, so the maximum almost always sits at lag 2.
- Three things push the short lags up regardless of layers:
  - the Sobel [1,2,1] smoothing raises lags 1 and 2;
  - the Hann-windowed estimate is tapered, which favours short lags;
  - a 50% blend averages out uncorrelated fine texture, which is TB1's finest-band dilution again.
- The ledger asked for the strongest *secondary* peak (LEDGER.md:504). The code departs from that without saying so.
- **Replacement** (keep the current value as `echo_raw`, printed only):
```python
WAC = np.fft.ifft2(np.abs(np.fft.fft2(HANN, s=(2*WIN, 2*WIN)))**2).real
RAD = np.array([int(round(np.hypot(dy, dx))) for dy, dx in LAGS])
def echo(gm, wins):
    if not wins: return np.nan
    W = np.stack([gm[y:y+WIN, x:x+WIN] for y, x in wins])
    W = (W - W.mean(axis=(1, 2), keepdims=True)) * HANN
    ac = np.fft.ifft2(np.abs(np.fft.fft2(W, s=(2*WIN, 2*WIN)))**2).real / WAC
    acn = ac / (ac[:, :1, :1] + 1e-12)
    g = lambda dy, dx: acn[:, dy % (2*WIN), dx % (2*WIN)]
    vals = np.stack([g(dy, dx) for dy, dx in LAGS], 1)
    ref = np.stack([np.median(vals[:, RAD == r], 1) for r in RAD], 1)
    nbr = np.stack([np.max(np.stack([g(dy+a, dx+b) for a in (-1, 0, 1) for b in (-1, 0, 1) if a or b], 1), 1)
                    for dy, dx in LAGS], 1)
    prom = np.where(vals >= nbr, vals - ref, 0.0)
    return float(np.median(prom.max(1)))
```
