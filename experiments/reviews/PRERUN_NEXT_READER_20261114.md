## Findings and rule mapping

1. **Resolved major: kernel seed counting.** The first reviewed draft required the same four seeds to pass both kernel quantities. Version 3(e) explicitly says each quantity passes on at least four seeds. The corrected code counts held-out and training-kernel passes separately, with a regression using different failing seeds. Storage(b) correctly retains its distinct joint requirement: the same four seeds pass both sizes. No rule text changed.
2. **Resolved major: admission role identity.** Preflight now binds candidate to the named arm and seed, comparator to same-seed Sb0, plain control to A0 or A512 as specified, and yardstick to same-seed exact-gated AB1 Sb. Original source SHA256 values are hard-pinned, not accepted from an arbitrary admission claim. Wrong arm, seed, control and source hashes are rejected before any candidate member is read. Fresh-source confirmation pins are intentionally unsupported until their registration and reviewed adapter extension exist.
3. **Detection(a): ok within current scope.** Full-landmark gain, strict positive-seed count, within-D mean/no-seed-loss bars, matched gain and half-full-gain bar use unrounded values and the exact approved inclusive/strict comparisons. The RZ1 refit gain must exceed the maximum eligible absolute same-seed refit difference. Ladder quintiles are recomputed on each sampled row set, with ten rows per class and n_pos × n_neg weighting. Component draws use default_rng(20261115), shared across networks, seeds and floors; the mean interval averages per-seed AUC differences, never scores. Required descriptive subsets and four floor families plus both transfer learners are printed. Final admission review must bind the exact previously fixed floor columns; arbitrary outcome-driven column choice remains prohibited.
4. **Criteria(b)–(f): ok for the registered RZ1 schema.** Storage compares flag-rate rises and retains plain-control and morph-evasion guards. TT1 is the unweighted mean of seven registered primary-family flag shares. MEDS uses the 865 primary rows and order-preserving 400-person groups, with 2,000 draws at seed 20261125 and upper bound ≤10%; identifiers stay in memory. S3 and the exact 1,582 border IDs use own-rule logit >0. Border path identity, transform/kernel provenance, finite losses, complete row order, manifest hashes and original full-manifest refit gates are checked. Native adapters do not infer a pass from scheduler completion.
5. **Counting, order and reporting: ok.** Failed/non-finite/missing seeds retain the denominator of five; all four valid seeds must meet a four-seed bar, and three or fewer are not read. Fixed challenger order decides, never observed gain. Selection and confirmation are distinct; fresh seeds 413–417 remain required before freeze. Development/selection-bias labels are retained. Original proposed RZ1 selection thresholds are superseded by approved version 3; they are not additional gates.
6. **DINOv3 bootstrap helper: scope checked.** Component replicates use the registered stream. Seed resampling uses an independent `SeedSequence(20261115).spawn(1)` stream, independently resampling candidate and comparator seeds in each shared component replicate. It does not reset the identical component RNG stream. This is a reasonable independent product bootstrap; it does not constitute a native DINOv3 adapter or its release.
7. **Fail-closed operations: ok with external admission still outstanding.** Preflight requires clean committed hashes, binding ancestry, reviewed exact admission bytes, arrival/hash receipts and the deadline. Unsupported arms are refused before candidate member access; implementation limitations cannot masquerade as scientific exclusions. Shared rows/floors are validated before claiming the fixed once journal. Candidate archive bytes are rehashed on the same file descriptor used for member reads; typed finite arrays reject unsafe/incomplete schemas. The atomic durable journal precedes the first scientific member read. Failure keeps the journal and forbids blind replay; recovery must reconcile recorded state rather than delete the marker. A batch-closed boolean alone is insufficient: the independent admission review must establish that eligible work is complete or has a legitimate fixed disposition.
