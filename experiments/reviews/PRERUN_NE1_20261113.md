## 2. Findings (most severe first)

**F1. Major: H0 and the other heads use different threshold rules.** In `src/NE1/ne1_heads.py:127-130`, H0 is cut at logit 0. H1-H4 are cut by `thr_at_share(...,k0)`, and with k0=0 that is their own highest score on the 417 camera photos (prereg.md:73-77). H0's own cut sits somewhere above its highest camera-photo score, and we don't know how far. So "border removal = 1 − flags(Hk)/flags(H0)" (prereg.md:85) compares heads at points that don't correspond. A single extreme photo moves every other head. The bootstrap also keeps the thresholds fixed (`ne1_heads.py:166,170`), so it hides exactly this weakness. Replace prereg.md:73-77 with:
> "Operating point. (a) Primary, no threshold: border shift = the mean over half-B hosts of [score(bordered copy) − score(same photo)], with scores converted to percentile ranks in the head's own genuine reference pool P = R_cam ∪ L ladder R0 (1,290 rows, 406 hosts). Removal = 1 − shift(Hk)/shift(reference head). (b) Secondary: every head, H0 included, is cut at the 99th and 95th percentile of its own scores on P. Flag shares are read there. (c) The old rule (k-th largest R_cam score) is printed only. The bootstrap redraws hosts in P and recomputes the thresholds in every draw."

Use the same paired, rank-based read for the storage effect Δf (prereg.md:90-91). H0's Δf is probably close to 0 at its own threshold, which leaves no room to show a drop of 0.02.

**F2. Major: the table can't separate erasure from refitting.** The border rows compare H3 with H0 (`ne1_heads.py:195-196`). H1 only adds a label when it also clears 70% (lines 197-201). So if H1 removes 60% and H3 removes 72%, the result still reads "separable". Fix:
- Add head **H0e**: the original w and b applied to the erased features, with no refit.
- Replace the separable row with: "H3 removes ≥ 70% of H1's border shift AND H0e removes ≥ 50% of H0's, AND landmark AUC(H3) ≥ AUC(H1) − 0.01."
- Apply the same idea to storage: compare H4 with H1, and H0e4 with H0.

**F3. Major: no null control and no positive control.** Add both, CPU only:
- **Null:** 20 rank-1 erasers along random directions drawn with the covariance of the T features (`default_rng(20261129)`), each followed by H1. H3 must beat the largest of the 20 on at least 4 of 5 seeds.
- **Positive control (ceiling):** an eraser fitted on half B, i.e. on the same rows it is read on. It shows the most a rank-1 mean-difference eraser can remove. If even this removes less than 70%, the border row reads "rank-1 erasure cannot test this", not "shared".
- **Check that erasure works:** erase the morph-minus-genuine mean direction of T, then apply H0e. Detection AUC must drop by at least 0.05. If not, the AUC guard is treated as insensitive.

**F4. Major: the splice result leans towards "not a weighting problem".** T is Sb's own training list. It already contains lad_S3 (156 rows, label 0) and lad_S4 (124 rows) (checked in `/mnt/t7/smad_next/NE1/ne1_train.csv`).
- Grouped cross-validation on features the network was trained on will likely put worst-group accuracy near 1.0 for every C. The tie rule (`ne1_heads.py:120`) then picks C=0.01.
- H2 then differs from H1 in both weighting and L2 strength, so the "H2 within 0.03 of H1" test mixes the two.
- Kirichenko et al. (DFR) refit the last layer on held-out data, not on the training set. The draft's citation describes their method wrongly.

Fix:
- Add H1d and H2d, fitted on the development hosts of L (100 hosts: R0 300, R2w 200, R4 400, S0/S3/S4 100 each).
- Read all splice results on the test hosts of L only (191 hosts).
- Add H1 refitted at H2's chosen C.
- Print T's worst-group accuracy for each C. If it is ≥ 0.98 for every C, the T-fitted splice row reads "not testable on in-sample features".
- The group DRO / JTT route is closed only if H2d also stays within 0.03.

**F5. Major: the outcomes claim too much.** A rank-1 mean-difference projection that fails doesn't show that "only data can help; no adversarial arm" (prereg.md:104), and "closed for this backbone" (prereg.md:107) goes too far as well. Replace with:
- "the border shift is not removable by a rank-1 linear eraser; gradient-reversal arms get no support from NE1"
- "reweighting the last layer on held-out development features does not move the trade-off"

Add `assert not ({x["host"] for x in T} & {x["host"] for x in G+R})`.

The splice rows use only H0-H2, so the table doesn't leak. But the script prints H3 and H4 splice reads for all hosts (`ne1_heads.py:141-145`). Restrict those to half-B hosts or label them.
