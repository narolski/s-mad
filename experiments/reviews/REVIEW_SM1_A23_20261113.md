**Verdict.** A23 was registered before it was computed, and the computation follows the registration. The table is sound. The comparison sentence needs qualifying: it puts outputs from different input paths next to each other without saying which pairing is like-for-like, and it leaves out the seed-variance caveat.

**(1) Registration and computation**
- Registration commit 80ba899 is at 08:59:31. `a23_rank_rel.json` was written at 08:59:49, after it. The read commit 6063e8b is at 09:00:05. The order is correct.
- `src/SM1/a23_rank_rel.py` matches `a12_rank.py` (the A14 definition): 5 KP over 5 KE per key, 25 pairs, ties count one half, mean over 500 keys. The bootstrap uses 10,000 key draws with `K.SEED`=20261111 (`sm1_common.py:27`). Scores are `logit_noTTA`, one network per release. No deviation.
- The "0.53–0.59" range checks out: ViT-B/16 arms c, b′, e, f give 0.533, 0.567, 0.562, 0.586 (`a12_rank_vitb12.json`).

**(2) Fairness**
- **F1 (major): which pairing is like-for-like.** The retrained ViT-L/14 was scored on whole images, so the comparison on the same input path is released whole-file 0.835 [0.825, 0.845] against retrained 0.756 [0.746, 0.765]. The crop path (0.768) is the release's own preprocessing, not a matched pairing. The result.md sentence lists crop first and implies the two are about equal.
- **F2 (major): intervals leave out seed variance on both sides.** In the ViT-B/16 arm a, the two seeds differ by 0.06 (0.727 vs 0.786). That is larger than the 0.012 crop gap between released and retrained ViT-L/14, and close to the 0.079 whole-file gap. With one released network and two retrained seeds, neither "similar" nor "higher" is supported.
- **F3 (minor): the logit gap and the AUC can rank paths in opposite orders.** For released ViT-L/14, the logit gap is larger on the crop path (0.95 vs 0.45) but the AUC is larger on whole files (0.768 vs 0.835). Say so: the logit gap must not rank paths or networks.
- **F4 (minor): MixFaceNet.** Its 13.36 logit gap mostly reflects how widely spread its scores are. Only the AUC (0.909 crop / 0.808 whole) can be compared across networks. It is a different architecture at a different resolution, so the comparison is descriptive.
- **F5 (minor): FS rows.** FS whole files were not scored, so the dash should read "not scored". The FS ViT-B/16 interval [0.513, 0.562] only just excludes 0.5.
