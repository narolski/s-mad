**Findings (most severe first)**

1. **Major: H-D's design cannot answer its question, and its outcome was known in advance.**
   - The floor's pair features (θ, c0–c3, lp8, zcos) are taken from the X20 or SAME20 source pair for every rung (`a21_read.py:162-173`). Only the four image statistics change between rungs. So the floor is in effect the X20-vs-SAME20 floor (0.992 / 0.995 in the addendum), relabelled as rung scores.
   - The network's rung AUCs were already public in A19 H-N1: 0.920 and 0.738 (`result.md:826-827`). A difference above 0.10 for SEMX was therefore certain before b43857a.
   - What "falsified" actually shows: the network is not a rung-blind function of source-pair similarity. It does not show that the network ignores render-path similarity.
   - The observed ordering (noise-only mixes 0.92, semantic-only mixes 0.72) fits a reading in which the network tracks noise-map similarity. A floor that matched each rung would set the unmixed component's pair features to their same-person values, e.g. SEMX gets the pair's zcos but the noise cosines of the host's own pair.
   - Fix: relabel the verdict "falsified as registered (outcome predictable from A19; uninformative about the noise-path reading)".

2. **Major: H-C over-claims.** H-C is a partial ρ *within* SEMS20 rows and *within* NOISES20 rows. It says nothing about the between-rung shift behind SEMS20 over REC20 = 0.93. A network could score every SEMS20 render higher because of a global departure from the reconstruction while showing no rank relation with MSE inside the rung. Pixel MSE is also only one measure of departure.

3. **Moderate: H-A is falsified only at quintile resolution.**
   - PNG quintiles are badly imbalanced: FRESH vs REC counts per quintile are 15/200, 62/152, 120/94, 144/70, 195/20. PNG size separates the classes, so confounding remains inside each quintile.
   - Arm a reaches 0.443 under PNG stratification, with seeds 0.398 / 0.488 straddling the 0.45 threshold. The host-bootstrap interval [0.413, 0.472] ignores seed variance.
   - The arm-e verdict stands (0.281 / 0.251, far below 0.40). The sentence "neither … explains" should be limited to arm e and to quintile stratification.

4. **Moderate: H-B has little power, and its label reads as contradicting the result.**
   - Dissimilarity (1 − cos_HB) is range-restricted: median 0.736, IQR 0.707–0.772. It correlates with PNG size (ρ −0.24) and asymmetry (−0.21), which are both in F.
   - The JSON label says "raw ρ −0.10 known", but the reported raw value is +0.102. These agree only because the known value was for cos_HB and the test uses 1 − cos. State that explicitly.
   - As in A19, the bootstrap keeps ranks and residuals fixed (`partial`, lines 29–37), so the interval is conditional.

5. **Minor: H-D network AUCs (0.922 / 0.718) differ from A19's (0.920 / 0.738)** because H-D uses the 67 shard-6 hosts only. Say so.

**What A21 changes for the paper's wording**

Nothing in A21 supports an identity (second-person) reading of diffusion-morph detection:
- H-B is undecided and A19 H-N2 is undecided.
- The A18 network adds nothing beyond noise-map similarity (ΔAUC −0.004 [−0.010, +0.004]).
- The rung ordering points to the render path (noise-map path) and away from identity.

Suggested sentence: "On development data from one DiffAE generator, the detector's two-person signal is not shown to exceed the similarity of the inverted noise maps. Its response follows noise-path mixing more than semantic mixing. We find no evidence that it reads a second identity." Do not write "render-path detection is shown": H-D does not test that.
