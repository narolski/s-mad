## Findings

**F1 (major). Amendment 6 and its code are not committed.** In `git status`, `experiments/AD4/prereg.md` (Amendment 6, lines 412-431), `src/AD4/fu_read.py` and `src/AD4/fu_pack.py` are modified, and `src/wcss/ad4_fu_h100.sbatch` is untracked. Hard rule 5 requires registration before the run, and an entry in the OWNER_BRIEF dispatcher queue needs "the registration commit" (OWNER_BRIEF.md:119). The amendment says "08:48", so without a commit that time cannot be checked. This is the same problem the PN1 review flagged (REVIEW_PN1_TIER1_20261112.md finding 5).
- Fix: commit before `sbatch`. Record in the README the sha256 of `fu_read.py` (currently 7823ddd9…), of the sbatch (220f616b…) and of the pack (e4b60874…, which matches its `.local.sha256`), as Amendment 6 requires.

**F2 (major). The reader prints a false flag.** `fu_read.py:133` and `:203` hard-code "Flag on the networks: not reproduced on this stack." But the WCSS arm passed the reproduction gate 11/11 (README.md:1137). Amendment 5(b) then requires the label "reproduced on the cluster stack". As written, the H100 tables would carry the wrong label.
- Fix: put the flag text behind an option (for example `--repro-flag`), or derive it from `ad4_gates_m3.json`. Do this before reading and record the new sha.

**F3 (major, bias risk). H-new-4 can only come out as a coin flip.** Amendment 6 keeps the Amendment 4 rule: supported if the pool median is below the FRLL genuine median in at least 3 of 5 morph-free seeds.
- On the DGX the differences were -0.03 and -0.05 logits. They sit inside a saturated floor whose 5th to 95th percentile spans about 0.03 (README.md:1077, 1081-1084). The review called "supported" wrong there (Subject 2).
- With five seeds, the sign of each difference is set by float noise at the floor. Deciding the "indistinguishable" wording after the numbers are seen would be a forking path.
- Fix (amendment text now, no GPU): keep the registered verdict, and register now that any |diff| smaller than the network's FRLL 5th-95th logit span is printed "indistinguishable at the trained floor". Add that column to the reader.

**F4 (minor). The gate counts only finite rows and ignores the limit.**
- `fu_read.py:68` drops non-finite rows before computing AUC and tau, and `limit` is recorded but never enforced (lines 81-85). A run with missing ids or a partial run could still pass.
- Also, H-new-3 output is silently skipped when any score is non-finite (line 116).
- Fix: when not in test mode, require `limit == 0` and every row of the cell present (`n == len(m) + len(b)`), and fail loudly rather than skip.

**F5 (minor). The pack check trusts a hash file stored next to the pack.** The follow-up pack is checked against `fu_pack_wcss.tar.sha256` in the same Lustre folder (sbatch:32). The AD4 pack, by contrast, is pinned (`PACK_SHA`).
- Fix: add `FU_SHA=e4b60874484eda7d444f550f7722824b9937610f6f569883ced88f8d52c44a83`.
- Optional: after extraction, also check the scorer's sha256 (`e0ab24b5…`) and that `build_info.json` says `networks_from == results_wcss_m3`.

**F6 (minor). The untrained network's gate is a cross-platform comparison.** Its reference is `zero_step/m3` (GB10, torch 2.12.1+cu130). The same network is rebuilt under torch 2.2.1 on an H100.
- The rebuild matches the reference path: the seeding in `fu_rescore.py` is the same as in `ad4_score.py:112`. At step 0 the LoRA B matrices are zero, so only the head initialisation matters.
- A miss is therefore unlikely. On the DGX against the rented cards the label-permuted networks reached tau ≥ 0.999. If it does miss, the reader drops the untrained network everywhere, and the H-new-3 tables turn "provisional (5 of 6 references)". That matches Amendment 6 ("only the reference row is lost"). OK as registered; state it in the README.

**F7 (minor). Amendment 6 leaves three rules implicit.**
- The "incomplete (k of 5)" rule comes only from Amendment 2(d). The reader implements it: H-new-3 at :127, H-new-4 at :161, H-new-5 at :198.
- Precedence should say "whatever the gate outcome", so that a WCSS result with fewer readable networks cannot be swapped back for the DGX rows.
- There is no remedy if a WCSS network misses the gate. Register "none; the network stays unread".
- Also, `v5` can be `None` (line 198) and would print "None".
