Operate on existing native512×512 RGB arrays in memory only. Occlude each non-overlapping64×64 square of an8×8grid, stride64, no cropping at edges. Two fixed constant fills: black RGB0 and gray RGB128, each replacing only pixels under the exact square. No blur, noise fill, inpainting, interpolation of response maps, image jitter or new morph generation. Apply precisely the existing model's standard ImageItems PIL-bilinear resize and RGB tensor conversion afterwards; a small memory adapter must reproduce the unchanged original loader's unmodified-image tensor exactly before inference. This is standard preprocessing, not a new image transformation. Published adapters keep their recorded input channel/normalization and attack-logit convention, aligned-frame scope only. No own-face recrop.

Geometric categories use only the shared native hull: seam ring = dilate(hull,17×17ones) minus erode(hull,17×17ones); surround = complement of dilate(hull,33×33ones); interior = erode(hull,33×33ones).
